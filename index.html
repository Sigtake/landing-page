Before you ask

Do I have to replace my current monitoring?
No. Sigtake sits downstream of whatever you already run — point an Alertmanager webhook or a cron job at the API and you are ingesting.
How does it decide two alerts are the same incident?
A fingerprint over source, title and severity, scoped to one project. The same failure in staging and production stays two separate incidents.
Who gets notified?
The team the API key belongs to, through that team's channels in that project. In-app push always lands, so nothing is lost while a channel is misconfigured.
What happens if a channel is down?
The dispatch retries with exponential backoff, and the failure is recorded rather than swallowed.
